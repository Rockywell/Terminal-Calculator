# Overview

To learn more about other languages and how to apply them. Here I'm learning more about C++ and its standard library and basic features so I can be flexible with different terminology and patterns within coding languages.

My program uses C++ to demonstrate a terminal calculator that uses console inputs and outputs to select basic arithmetic and perform operations. I use C++ to write and read from files and store to a vector for the history of completed operations. This acts as a basic user interface for a basic calculator in the console.

I wrote this software to test my understanding of the language and give myself an opportunity to exercise how I organize and use the standard library within C++.
